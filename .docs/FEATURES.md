
# Feature Wishlist & Specs


## Core Text Engine Components

### Block-Level Text Behavior
- [ ] **No-Newline Text Inputs:** Every text block acts as an isolated, single-line input node.
- [ ] **Enter Key Routing:** Pressing `Enter` spawns a new default text block below the focused block and shifts focus.
- [ ] **Block Merging:** Deleting past index `0` joins the current block with the block above it.
